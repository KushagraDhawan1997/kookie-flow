Kookie Flow supports grouping entities together with frames, adding annotations with comments, and creating edge waypoints with reroutes.

## Frames

Frames are container entities that can hold other entities as children. When a frame is collapsed, all its children are hidden.

### Creating a Frame

```tsx
import type { Entity } from '@kushagradhawan/kookie-flow';

const entities: Entity[] = [
  // Frame entity (container)
  {
    id: 'frame-1',
    type: 'frame',
    position: { x: 0, y: 0 },
    data: { label: 'Processing Pipeline' },
    width: 400,
    height: 300,
    collapsed: false, // Set to true to hide children
  },
  // Child entities (reference parent via parentId)
  {
    id: 'entity-1',
    type: 'default',
    parentId: 'frame-1',
    position: { x: 20, y: 50 }, // Position relative to parent
    data: { label: 'Input' },
  },
  {
    id: 'entity-2',
    type: 'default',
    parentId: 'frame-1',
    position: { x: 20, y: 150 },
    data: { label: 'Output' },
  },
];
```

### Collapsing Frames

Toggle the `collapsed` property to show/hide children:

```tsx
function handleToggleCollapse(frameId: string) {
  setEntities(entities.map(entity =>
    entity.id === frameId
      ? { ...entity, collapsed: !entity.collapsed }
      : entity
  ));
}
```

When collapsed:
- All descendant entities are hidden from the viewport
- Edges connected to hidden entities remain visible (connected to the frame boundary)
- The frame displays a collapse indicator

### Frame Properties

| Property | Type | Description |
|----------|------|-------------|
| `type` | `'frame'` | Identifies the entity as a frame |
| `collapsed` | `boolean` | Whether children are hidden |
| `parentId` | `string` | Parent frame ID (for nested frames) |
| `extent` | `'auto' \| 'fixed'` | How frame bounds are calculated |

### Nested Frames

Frames can be nested inside other frames:

```tsx
const entities = [
  { id: 'outer', type: 'frame', data: { label: 'Outer' } },
  { id: 'inner', type: 'frame', parentId: 'outer', data: { label: 'Inner' } },
  { id: 'entity', parentId: 'inner', data: { label: 'Deeply Nested' } },
];
```

## Comments

Comment entities are sticky notes for adding annotations to your graph. They render as DOM elements with customizable styling.

### Creating Comments

```tsx
const comment: Entity = {
  id: 'comment-1',
  type: 'comment',
  position: { x: 500, y: 100 },
  width: 200,
  height: 100,
  data: {
    content: 'This section handles user authentication.\n\nRemember to validate tokens!',
    backgroundColor: '#FFF9C4', // Light yellow (default)
    textColor: '#424242',       // Dark gray (default)
    fontSize: 14,               // Default: 14
  },
};
```

### Comment Styling

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `content` | `string` | - | Text content (supports line breaks) |
| `backgroundColor` | `string` | `#FFF9C4` | Background color |
| `textColor` | `string` | `#424242` | Text color |
| `fontSize` | `number` | `14` | Font size in pixels |

### Color Presets

Common sticky note colors:

```tsx
const colors = {
  yellow: '#FFF9C4',
  blue: '#BBDEFB',
  green: '#C8E6C9',
  pink: '#F8BBD9',
  orange: '#FFE0B2',
  purple: '#E1BEE7',

```

## Reroute Entities

Reroute entities are edge waypoints that help organize complex graphs. They appear as small circles that edges can pass through.

### Creating Reroutes

```tsx
const reroute: Entity = {
  id: 'reroute-1',
  type: 'reroute',
  position: { x: 200, y: 150 },
  data: {},
};

// Connect edges through the reroute
const edges = [
  { id: 'e1', source: 'entity-1', target: 'reroute-1' },
  { id: 'e2', source: 'reroute-1', target: 'entity-2' },
];
```

### Reroute Behavior

- Rendered as small WebGL circles (instanced for performance)
- Can be selected and dragged like regular entities
- Act as connection points for edges
- Useful for routing edges around obstacles

### Visual Style

Reroutes display as:
- Small circle (8px radius)
- Cross pattern inside when not selected
- Highlight ring when selected
- Match the theme's accent color

## Store Actions

The Zustand store provides actions for managing frames:

```tsx
import { useFlowStoreApi } from '@kushagradhawan/kookie-flow';

function FrameControls() {
  const store = useFlowStoreApi();

  return (
    <>
      <button onClick={() => store.getState().toggleGroupCollapse('frame-1')}>
        Toggle Collapse
      </button>
      <button onClick={() => store.getState().expandGroup('frame-1')}>
        Expand
      </button>
      <button onClick={() => store.getState().collapseGroup('frame-1')}>
        Collapse
      </button>
    </>
  );
}
```

### Available Actions

| Action | Description |
|--------|-------------|
| `getGroupChildren(frameId)` | Get direct children of a frame |
| `getGroupDescendants(frameId)` | Get all descendants (recursive) |
| `toggleGroupCollapse(frameId)` | Toggle collapsed state |
| `expandGroup(frameId)` | Expand a collapsed frame |
| `collapseGroup(frameId)` | Collapse an expanded frame |
| `isGroupCollapsed(frameId)` | Check if frame is collapsed |
| `getGroupBounds(frameId)` | Get bounding box of frame contents |

## Entity Changes

Handle grouping-related changes through `onEntitiesChange`:

```tsx
import type { EntityChange } from '@kushagradhawan/kookie-flow';

function handleEntitiesChange(changes: EntityChange[]) {
  for (const change of changes) {
    switch (change.type) {
      case 'collapse':
        // Frame collapsed/expanded: change.id, change.collapsed
        console.log(`Frame ${change.id} collapsed: ${change.collapsed}`);
        break;
      case 'parent':
        // Entity reparented: change.id, change.parentId
        console.log(`Entity ${change.id} new parent: ${change.parentId}`);
        break;
    }
  }
}
```

## Performance

Grouping features are optimized for large graphs:

- **O(1) visibility checks**: Hidden entities are pre-computed into a Set
- **Efficient collapse**: Only rebuilds when collapse state changes
- **Instanced rendering**: Reroute entities use WebGL instancing
- **Frustum culling**: Hidden and off-screen entities skip rendering
