# Home plan images

Home draws each starter's plan with one picture per step, loaded from
`apps/studio/public/home/<starter>/<step>.webp`. A missing file shows a plain grey slot, so drop
files in as they are made; no code change needed. 4:3 unless noted; about 800 px wide is plenty.

| File | Picture |
| --- | --- |
| `concept/ask.webp` | Optional. A rough reference sketch of a handheld console controller. |
| `concept/draft.webp` | Four rough concept renders of the controller in one 2×2 sheet, varied styles. |
| `concept/pick.webp` | The one draft chosen from the sheet, on its own. |
| `concept/final.webp` | A polished product render of that chosen controller. |
| `launch/ask.webp` | A plain product shot of a new sneaker. |
| `launch/prepare.webp` | The same sneaker, cut out on white. |
| `launch/draft.webp` | Three rough scene placements of the sneaker in one sheet. |
| `launch/pick.webp` | The chosen scene, rough. |
| `launch/final.webp` | The chosen scene, finished, with matched light. |
| `animate/ask.webp` | 16:9. A still of a mountain ridge at dawn. |
| `animate/draft.webp` | 16:9. Two low-resolution frames from different takes, side by side. |
| `animate/pick.webp` | 16:9. The chosen take's frame. |
| `animate/final.webp` | 16:9. The chosen take at full resolution, mist over the ridge. |
| `relight/ask.webp` | A plain portrait photo. |
| `relight/prepare.webp` | The person cut out. |
| `relight/draft.webp` | The portrait in three lights (golden hour, studio, overcast) in one sheet. |
| `relight/pick.webp` | The chosen light, rough. |
| `relight/final.webp` | The chosen light, finished. |
