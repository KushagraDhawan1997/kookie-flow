# @kushagradhawan/kookie-flow-skin-glass

KookieUI v2's glass look for Kookie Flow: which token plays each colour role, the sizes and radii,
the shader code for cards, controls, the popover and media chrome, and the toolbar's components.

```tsx
import { KookieFlow } from '@kushagradhawan/kookie-flow-react';
import { glassSkin } from '@kushagradhawan/kookie-flow-skin-glass';

<KookieFlow skin={glassSkin} entities={entities} edges={edges} />;
```

Part of [Kookie Flow](https://github.com/KushagraDhawan1997/kookie-flow).
See [package installation and migration](https://github.com/KushagraDhawan1997/kookie-flow/blob/main/docs/PACKAGES.md).

These packages are pre-1.0 candidates. Keep sibling Flow packages on the same release.
