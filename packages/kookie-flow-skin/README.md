# @kushagradhawan/kookie-flow-skin

Kookie Flow's skin on KookieUI v2's tokens (today, its glass material): which token plays each
colour role, the sizes and radii, the shader code for cards, controls, the popover and media
chrome, and the toolbar's components.

```tsx
import { KookieFlow } from '@kushagradhawan/kookie-flow-react';
import { skin } from '@kushagradhawan/kookie-flow-skin';

<KookieFlow skin={skin} entities={entities} edges={edges} />;
```

Part of [Kookie Flow](https://github.com/KushagraDhawan1997/kookie-flow).
See [package installation and migration](https://github.com/KushagraDhawan1997/kookie-flow/blob/main/docs/PACKAGES.md).

These packages are pre-1.0 candidates. Keep sibling Flow packages on the same release.
